- 宿主沿原200 Hz循环直接使用当拍 `getEncVel[0]`。先计算并限制阻尼，再按实际Stopwatch间隔限制环境力变化率，最后合成限幅；输出无效时保留零力逻辑并复位环境力历史。扭矩继续原样下发。
- `Program.cs` 顶部常量为 `DAMPING_B=0.01`、`DAMPING_SIGN=1`、`DAMPING_MAX_N=0.5`、`FORCE_SLEW_N_PER_S=8`、`FORCE_MAX_N=1.2`、`SHOW_FORCE_CONSOLE=true`。HandleService中同名显示常量同样为true。
- 控制台每200 ms一行，包含两只手柄的原始速度、实际阻尼、变化率限制后的环境力、最终输出及阻尼截断标志；无效侧只显示“力反馈未生效”。生产宿主不写力日志文件。
- 删除数据端 `apply_damping`、阻尼配置项以及仅按原运动方向释放保持的旧字段/参数。轴向力低通alpha仍为0.25，独立于保持开关。
- 换手锁存100 ms时间常数平滑后的力与扭矩。完成换手后，任意方向移动至少2 mm或等待400 ms，开始300 ms线性过渡；相关时间使用steady_clock。
- `force.csv` 在原16列后追加 `ff_582_out_f,ff_582_out_n,ff_587_out_f,ff_587_out_n,hold_582_active,hold_587_active`；schema_version从7升为8。前四列为数据端环境力/扭矩，未包含宿主本地阻尼与限幅。
- 主端和数据端的[力反馈说明](../../B数据端/工程/docs/guides/力反馈说明.md)及实验记录说明已同步更新。

## 现场调参步骤

1. **看阻尼力的大小。** 启动主端后会弹出手柄宿主控制台。开启力反馈，以平时操作速度推拉，观察“速度原始值”和“阻尼力”。正常操作速度下阻尼力绝对值目标约0.2～0.4 N。若远低于此范围（例如只有0.00x N），按“目标阻尼力绝对值÷速度原始值绝对值”估算新的 `DAMPING_B`；频繁出现“阻尼限幅=是”时按同一公式调小。公式使用实际推拉时的非零速度值。
2. **阻尼方向。** 机器人不接触任何东西，取零后开启该侧力反馈，此时环境力约0。推拉感觉变沉说明方向正确；如果手柄被带着走或越推越快，立即关闭力反馈，把 `DAMPING_SIGN` 改为−1并重新编译。
3. **振荡。** 复现之前容易振荡的推拉动作。还振荡时，在阻尼力不超过约0.5 N的前提下增大 `DAMPING_B`。换向时力翻转太突然，把 `FORCE_SLEW_N_PER_S` 降到5；力跟不上则升到12。
4. **编译与隐藏控制台。** 修改 `VI.HandleHost/Program.cs` 顶部常量后重新编译主端即可。调好后，把Program.cs和HandleService.cs两处 `SHOW_FORCE_CONSOLE` 同时改为false，再编译并重启主端以关闭控制台窗口。

未做完整验收或实机调参。getEncVel单位仍未确认，阻尼大小、方向和振荡表现需按上述步骤现场判断；定位臂历史回归失败保留待其所属任务处理。
