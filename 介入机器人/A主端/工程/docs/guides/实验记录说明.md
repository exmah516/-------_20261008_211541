# 实验记录说明

数据端 `experiment_recorder.*` 和 `async_csv_writer.h` 负责记录；`AdsControlUI` 已移除，当前随包 UI 无实验会话开始/停止入口。后端 `VisCommandType::StartExperimentRecording(25)`、`StopExperimentRecording(26)` 与 `VisServer` 仍保留，本次未新增主端实验入口。记录与运动控制、力反馈开关和调零分别管理，未调零时仍可保存原始力数据。

## 会话文件

输出相对于 ADS 进程的当前工作目录：`records/YYYYMMDD/HHMMSS_实验名称/`，重名时追加编号。正常入口的工作目录为 ADS 程序输出目录。

- `force.csv`：目标 100 Hz，记录两组传感器原始电压、零点、轴向力、手柄扭矩及有效标志。
- `motion.csv`：目标 50 Hz，记录七轴相对左端位置，以及 axis1/axis6 手柄平移、转动的原始值、滤波值和有效标志。
- `session.json`：会话时间、配置、写入统计和丢样统计。

时间轴使用 QPC，`elapsed_us` 为相对会话起点的微秒数。力样本跟随 ADS 快照序号；运动样本取偶数序号。通信缺失和无效数据通过有效标志及 NaN 表达，不能把缺样当成零值。

开始时创建两份 CSV，失败会回滚；采集线程入队，异步线程写盘，停止时排空队列并写入会话元数据。字段的完整顺序以 `experiment_recorder.cpp` 中的 CSV 表头为准。

本会话只记录上述三个文件。影像采集和发送由独立的 `影像传输` 工程负责。
