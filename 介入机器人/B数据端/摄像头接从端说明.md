# 海康摄像头接从端，主端监控1显示

## 第一步：接线并设置地址

摄像头接介入机器人 B 数据端 的独立 USB 网口并保持供电。摄像头保留 `192.168.1.64`，USB 网口设为 `192.168.1.96`，掩码均为 `255.255.255.0`；USB 网口不填默认网关。主从直连网口继续使用 A `192.168.50.1`、B `192.168.50.2`，掩码也是 `255.255.255.0`，不填网关。摄像头无需增加通往 A 的网关，因为摄像头只与 B 的 USB 网口建立连接。

如果 C 的倍福网口也在 `192.168.1.x/24`，在 USB 网口的 IPv4 高级设置里取消“自动跃点数”，将 USB 网口跃点数设为 `5000`，使它高于原有倍福网口的跃点数。原有倍福网卡、PLC 地址和 ADS Route 保持不变。程序会用 `IP_UNICAST_IF` 和源地址绑定把摄像头连接固定到 USB 网口；提高 USB 跃点数是为了避免其他程序访问同网段的 PLC 时选到 USB 网口。程序本身不会添加系统路由、网桥、网络共享或 Windows portproxy 规则。

## 第二步：照常启动从端

打开 `工程\ADS项目\ADS.sln`，选择 `x64` 和 `Debug` 或 `Release`，编译并运行；也可以继续使用原有“编译并启动从端.cmd”。摄像头 TCP 转发已编译在 ADS.exe 内，随程序自动启动和退出，不需要额外启动脚本、辅助进程、海康 DLL 或 iVMS。运行 ADS.exe 无需因视频转发而提升管理员权限。

控制台出现 `[Camera] 监听 192.168.50.2:18000 -> 192.168.1.64:8000，USB源地址 192.168.1.96` 表示已开始等待主端连接，不代表已经取得画面。摄像头未接入、USB 地址不匹配或视频连接失败时会输出独立的 `[Camera]` 错误；视频功能不参与 PLC 读写、手柄控制权或运动状态机。视频最多接受主端 `.50.1` 的八条并发 TCP 连接，供海康 SDK 的登录、控制及媒体连接使用。

## 第三步：打开主端监控1

主端 `介入机器人/A主端/工程/config/hik_cameras.ini` 的 `[camera1]` 已改成下面两个值，原有账号、密码、通道和码流不变。继续保留主端现有海康 DLL 和播放器，监控2配置不变。

```ini
ip=192.168.50.2
port=18000
```

实际连接是 A `.50.1` 主动访问 C `.50.2:18000`，C 再从 USB `.1.96` 连接摄像头 `.1.64:8000`，视频沿已建立的连接返回 A。不是让摄像头主动连接 `.50.1`。先启动 C，再打开 A 的 MasterConsole 并选择“监控1”。原播放器启动登录失败时不会自行重试登录，待 C 和摄像头准备好后重新打开主端即可。看视频无需申请机器人控制权或点击开始控制。

## 第四步：首次放行防火墙

在 C 上用管理员 PowerShell 执行以下一次性设置，允许 A 访问视频端口。此规则不改变原有 TCP 32000、UDP 32001 控制链路。A 若采用默认允许出站的 Windows 防火墙策略，不需新增入站规则；若有额外出站限制，则放行 A 到 C `.50.2:18000` 的 TCP。不要关闭整个防火墙。

```powershell
New-NetFirewallRule -Name VesselCamera1Relay -DisplayName "ADS 摄像头1转发" -Direction Inbound -Action Allow -Protocol TCP -LocalAddress 192.168.50.2 -LocalPort 18000 -RemoteAddress 192.168.50.1 -Profile Any
```

## 第五步：判断连接是否正常

在 A 执行 `Test-NetConnection 192.168.50.2 -Port 18000`，成功说明到从端监听端口可达；最终以监控1中连续变化的真实画面为准。测试端口成功仍黑屏时，检查 C 的 `[Camera]` 错误、USB 网口 `.1.96`、摄像头 `.1.64:8000` 和原有摄像头账号。`10049` 通常表示指定本机地址不存在，`10048` 表示监听端口被占用，`10061` 表示目标拒绝连接。若曾手工建立同端口的 Windows portproxy，先撤销那条旧规则，避免与 ADS.exe 重复监听。

转发保持原压缩码流，不解码、不重编码，不改变摄像头码率。关闭 ADS.exe 会同时断开视频转发。若要恢复原来的主端直连，重新将摄像头接到 A 可访问的网络，并把上述 `[camera1]` 两项改回 `ip=192.168.1.64`、`port=8000`。

以后修改地址或端口：从 B 数据端集中修改 `工程\ADS项目\hik_camera_relay.h` 的 `HikCameraRelayConfig` 默认值并重新编译；主端修改现有 `hik_cameras.ini`。本次没有修改 PLC 工程。
