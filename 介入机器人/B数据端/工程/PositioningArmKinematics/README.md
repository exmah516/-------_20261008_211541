# 定位臂 Eigen 运动学

数学模块只依赖Eigen，不连接ADS；现已由原ADS工程直接编译，并接入原WPF界面、
ArmManualAdsService和`介入机器人/C从端/250902/Untitled2`的PLC源码。不使用Pinocchio、Pink或Python。

## 依赖与构建

- MSVC x64，当前工程使用 `v142`。
- CMake 3.24 或更高版本。
- Eigen 3.4 或更高版本。

如果本机没有 Eigen，可使用 Conda 安装到模块目录：

```powershell
conda create --prefix .deps --override-channels -c conda-forge eigen=3.4.0 --yes
```

构建并运行离线测试：

```powershell
.\BuildAndTest.ps1 -Toolset v142
```

也可以直接指定 Eigen 安装前缀：

```powershell
.\BuildAndTest.ps1 -EigenRoot 'D:/path/to/eigen-prefix'
```

## 坐标与模型

全部运动学输入和输出采用倍福机械零位对应的坐标，轴1用米，轴2至5用弧度；程序角只用于显示，不可再次传入机械角接口。

- 基座 XYZ 固定，+Z 向上，轴2至4位置增大表示绕 +Z 逆时针旋转。
- 倍福机械零位（轴2～5均为0°）时，轴2到3沿 -Y，轴3到4沿 +Y。
- 该零位下工具坐标相对基座绕 +Z 旋转 -90°：工具 +X 沿基座 -Y，工具 +Y 沿基座 +X，工具 +Z 沿基座 +Z；工具前端沿工具 -Y，即基座 -X。
- 程序归零目标就是倍福机械零位：轴2=0°、轴3=0°、轴4=0°、轴5=0°。
- 轴5机械角减小使前端抬起。对外的俯仰点动“抬头为正”。
- 固定安装高度被省略，`forward().position.z()`是虚拟高度，不能当成离地高度或避碰依据。
- 默认几何尺寸已填入；调用方仍须提供速度和编码器换算。本次ADS笛卡尔规划对轴1～4不设软件位置限位，仅轴5限制±60°。
- 轴1实际行程为200 mm，但行程不确定上下端点的读数。测试中的0~200 mm端点不是实机标定。

编码器换算和程序显示换算分开：

```text
mechanical[i] = (encoder[i] - calibration[i].zero) * scale[i] * direction[i]
program[1..4] = mechanical[1..4]
program[0] = mechanical[0]
```

倍福读数已是机械零位角度时，轴2至5的`zero=0, scale=pi/180, direction=+1`。
轴1已确认为毫米，比例为0.001，无需填写下端读数。窗口内判定到位不会改写编码器、修改偏置或伪造精确零读数。

模型公式（长度为米、`q`为机械坐标）：

```text
a = q2 + q3 + q4 - pi/2
p = [0, 0, q1]
  + 0.200 * [sin(q2), -cos(q2), 0]
  + 0.180 * [sin(q2+q3+pi), -cos(q2+q3+pi), 0]
  + Rz(a) * Rx(q5) * [0.4563, -0.5545, 0]
Q = Quaternion(Rz(a) * Rx(q5))
```

零位时工具偏航`a=-pi/2`，两根连杆反向折叠，前端虚拟位置为`[-0.5545,-0.4763,q1] m`。
位置Z省略固定安装高度，只用于增量控制。

## 点动接口

- `solveJog(current, {JogAxis, speed, duration})`：单模式带符号速度点动，平移米/秒，旋转弧度/秒。
- `solveCartesianJog`：直接指定小步位移的底层接口，拒绝同时给多个非零分量。
- X/Y：只动轴2、3、4，保持偏航；偏航：只动轴2、3、4，保持前端位置。
- Z：只动轴1；俯仰：只动轴5，允许前端圆弧移动。
- `solveJog`在近奇异区缩小实际点动速度，返回`speed_scale`；底层指定距离接口不改变请求距离，无法满足则拒绝。
- 平面点动逆解采用两连杆解析解，带限位、单步速度约束与支路连续检查；位置和姿态目标由解析几何直接确定。
- `forward` / `computePose`用于当前位姿计算，`computeFrameJacobian`用于点动切向速度和奇异检查；解析IK不做额外的正解迭代复核。
- `fromEncoder` / `toEncoder`仅转换机械角；`toProgramCoordinates` / `fromProgramCoordinates`转换显示角。

程序零位是平面折叠奇异位，XY/偏航不能从该位正常启用任意方向点动。
Z、俯仰与专用关节回位不经过平面逆解，不被这个奇异状态一并禁用。

## 程序归零

规划接口由ADS后台调用，不是倍福硬件找零，不会调用`MC_Home`或重置任何机械零点。

1. `isAtProgramZero`分别检查轴2～4机械读数0°±3°、轴5读数0°±1°，包含边界。
2. 四轴全部在窗口内时，`planProgramZeroReturn`返回`AlreadyAtZero`，目标为原始状态，轨迹为空，不强制精确对齐。
3. 窗口外时规划回到精确机械目标0°、0°、0°、0°，轴1保持输入位置。
4. 四个旋转轴均向目标单调运动，不夹紧关节终点、不用±360°等价角绕过限位。
5. 使用有界四参数关节曲线，局部优化前端相对起点的位置偏离与四元数姿态偏离，加上微小关节路径惩罚。它是低扰动启发式，不保证全局最优或末端完全不动。
6. 采用五次时间律；根据连续导数上界延长时间，使关节速度和加速度不超过配置值，首尾速度、加速度为零。
7. 返回末端偏离与姿态变化上界，供查看轨迹效果；不再要求手填行程、偏离或转角预算。

`HomeOptions.max_acceleration`由ADS读取各旋转轴当前加速度配置，
关节速度使用`ArmKinematicConfig.max_velocity`。界面点击归零即可发起规划。

动力学配置、限位或采样数不满足时，返回相应错误，`target`保持输入、`samples`为空。
正常回位返回带时间、位置、速度、加速度的样本及位移/转角上界，可用于离线预览。

ADS发送曲线起点、终点、弯曲系数和时间，PLC使用与数学模块相同的五次时间律。
任意更换插补方式、重新定时或只发送最终位置都会丢失这些轨迹约束。
没有对运动曲线加加速度做额外约束；停止功能块使用原单轴区域配置的减速度和加加速度。

## 末端点动与部署

末端按住点动已改为PLC的ArmCartJog/ArmCartJogGen逐1ms生成；数据端只转发请求和保活。
归零继续使用原17个LREAL的单段五次曲线，第16项必须为0。单轴点动仍为MC_MoveVelocity。
末端点动不再使用本库的solveJog或solveCartesianJog，也不修改单轴点动的参数。
