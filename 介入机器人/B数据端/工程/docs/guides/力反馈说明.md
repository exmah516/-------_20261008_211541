# 力反馈说明（当前实现）

## 1. 采集数据

数据端从倍福 ADS 读取四路有符号 INT16，通信周期约 100 Hz：

- `G.fn_1_value`
- `G.ft_1_value`
- `G.fn_2_value`
- `G.ft_2_value`

原始值按 `raw / 1000.0` 换算为 V。轴 2 相对位置同时读取，但当前只保留给导管侧历史重力补偿接口，在线重力补偿仍关闭。

## 2. 零点

主端“力反馈取零点”会连续等待并采集3帧有效ADS数据，四路电压和轴2位置分别取平均值。尚未取零时首次开启反馈也会自动采集；已有零点后，切换两侧开关不重新取零：

- `f_zero`
- `ft_zero`
- `fn_2_zero`
- `ft_2_zero`
- `theta0_deg`

后续只使用“当前值 - 零点”的差值，因此标定截距自然抵消。

## 3. 标定和输出

第一层为传感器本体标定（2026-11-02 用户提供），以 ADS 原始计数为输入：

| 对象 | 通道 | 斜率（N/count） |
|---|---|---:|
| 导管 | fn_1 | 0.000319519429 |
| 导管 | ft_1 | 0.000703683250522 |
| 导丝 | fn_2 | 0.001134444473 |
| 导丝 | ft_2 | 0.000133373639 |

程序保留 raw/1000.0 V 的采样形式，对应 N/V 斜率为上表的1000倍，只换算一次。

第二层为安装后的系统标定，导管与导丝共用：

- 轴向力：`F_abs = 1.80 × F_sensor + 0.183108 N`
- 力矩：`T_abs = 18.440851 × Ft_sensor + 0.020906`，单位 N·mm

在线先扣除当前装机零点，因此两层固定截距都抵消，实际使用 `F = 1.80 × ΔF_sensor`、`T = 18.440851 × ΔFt_sensor × 0.001 N·m`。参数集中在数据端 force_calibration.h；不再叠乘旧 k_feedback，也不再乘3 mm半径。

当前死区和限幅：

- 轴向力死区：0.02 N
- 力矩死区：0.01 N·mm（0.00001 N·m）
- 轴向力限幅：±5 N
- 力矩限幅：±20 N·mm

两层标定后的物理量先经过现有死区和限幅，再按物理手柄分别乘 ControlConfig 中的四个反馈比例，默认均为0.3：

    double force_feedback_582_force_scale = 0.3;  // 导丝582：力
    double force_feedback_582_torque_scale = 0.3; // 导丝582：扭矩
    double force_feedback_587_force_scale = 0.3;  // 导管587：力
    double force_feedback_587_torque_scale = 0.3; // 导管587：扭矩
    double force_feedback_force_filter_alpha = 0.25; // 轴向力一阶低通

四项互相独立，替代原公共比例，不叠乘旧系数。对应手柄的力、扭矩比例都设为 0.5 时，原反馈 1 N、2 N·mm 变为 0.5 N、1 N·mm；设为 0 仅将该分量归零。force.csv 原有纯净测量列不受反馈比例影响，新增数据端输出列反映反馈比例及保持结果。修改后重新编译并部署数据端。

数据端只发送环境力：标定轴向力先做一阶低通（`force_feedback_force_filter_alpha = 0.25`），再乘对应比例并经过换手保持。低通在输出有效时始终启用，“开启保持/关闭保持”仅控制换手保持。扭矩沿用原比例及保持通道。

主端 `VI.HandleHost/Program.cs` 在原有200 Hz循环内，用本周期 `getEncVel` 第一通道原始值计算阻尼，不对位置求导。每只手柄独立计算：

1. `F_damp = clamp(-DAMPING_SIGN × DAMPING_B × Velocity[0], -DAMPING_MAX_N, +DAMPING_MAX_N)`。
2. `F_env_lim` 向数据端环境力靠近，每拍变化不超过 `FORCE_SLEW_N_PER_S × Δt`；`Δt` 使用 `Stopwatch` 的实际间隔。
3. `F_out = clamp(F_env_lim + F_damp, -FORCE_MAX_N, +FORCE_MAX_N)`，下发到 `vector[force.Axis]`，扭矩原样下发。

沿用 Enable、Tick新鲜度3 s和设备有效判断；输出无效时沿原逻辑清零，并将 `F_env_lim` 复位为0。阻尼只在对应手柄力反馈有效时生效。

参数直接写在 `VI.HandleHost/Program.cs` 顶部，不增加配置文件或界面开关：

| 常量 | 默认值 | 含义 |
|---|---:|---|
| `DAMPING_B` | 0.01 | N / getEncVel原始单位；沿用原数据端系数 |
| `DAMPING_SIGN` | 1 | 正速度产生负阻尼力；反向时改为−1 |
| `DAMPING_MAX_N` | 0.5 | 阻尼力绝对值上限，N |
| `FORCE_SLEW_N_PER_S` | 8 | 环境力变化率，N/s；0到1.2 N约150 ms |
| `FORCE_MAX_N` | 1.2 | 合成轴向力上限，N |
| `SHOW_FORCE_CONSOLE` | true | 显示宿主控制台并每200 ms打印一行双手柄力信息 |

`VI.Service.Robot/Services/HandleService.cs` 同名 `SHOW_FORCE_CONSOLE` 常量应保持同值；true时以 `CreateNoWindow = false` 启动宿主，false时恢复隐藏窗口。582.dat、587.dat 的堵转峰值约1.74 N，最终输出上限1.2 N低于该值。

控制台每行含582、587两段；“环境力”是宿主变化率限制后的 `F_env_lim`，“阻尼限幅”表示该周期原始阻尼力是否被±0.5 N截断：

```text
   [582] 速度原始值=+0.0000  阻尼力=+0.000 N  环境力=+0.000 N  输出=+0.000 N  阻尼限幅=否   [587] 力反馈未生效
```

无效侧只打印 `[序列号] 力反馈未生效`。宿主只打印，不写文件。

## 4. 固定手柄映射

力反馈不再根据 `GuidewireMode`、单手柄或双手柄切换：

- 导管 `fn_1 + ft_1` 的结果固定发送到控制轴1的物理 SN587
- 导丝 `fn_2 + ft_2` 的结果固定发送到控制轴6的物理 SN582

主端状态区对应显示两组四个值：

- 导丝：轴向力、力矩（SN582）
- 导管：轴向力、力矩（SN587）

这里显示数据端发出的环境力与扭矩，受反馈开关、比例、死区、低通和保持影响。主端本地阻尼、环境力变化率限制和最终限幅后的实际指令只在宿主控制台显示，界面字段保持不变。force.csv 的两组纯净测量值不受这些输出策略影响。

## 5. 输出门控

只有以下条件同时满足时才输出非零力：

```
对应手柄的力反馈已开启
控制已激活
不在急停保持
零点已完成
当前 ADS 力采样有效
```

导丝开关仅控制SN582，导管开关仅控制SN587；关闭一侧会清零该侧力/扭矩并清除该侧锁存，另一侧继续原有输出。控制未激活、PLC急停或未取零时两侧输出均为零；力采样短暂无效时沿用已有换手锁存，否则输出零。

结构补偿恒力已删除。重力补偿和旧解耦矩阵仍不参与在线输出。

## 6. 保留的动作策略

- 每侧对低通、比例处理后的轴向力及原比例扭矩额外维护慢速平滑值，系数 `1 - exp(-Δt / 100 ms)`，按实际周期更新。慢速平滑只用于换手锁存，不叠加到正常实时输出通道。
- 自动换手触发时锁存相关手柄的慢速平滑力与扭矩，在回退、重新递送及夹爪恢复期间保持不变。默认开启，关闭保持会清除锁存，但低通和主端本地阻尼继续按各自条件工作。
- 夹爪恢复、最终重同步完成后，以对应轴当前绝对位置作为 `resume_origin_abs`，并记录完成时刻。轴1/轴6向任一方向移动至少2 mm，或自完成起达到400 ms，满足任一条件即开始300 ms线性过渡回实时力与扭矩。保持在过渡完成后撤销。
- 以上时间统一采用 `steady_clock` 毫秒数。传感器采样短暂无效时沿用已有锁存保留与恢复行为。

## 7. 现有通信时效

主端状态帧超过2 s视为过期；有效触觉帧超过3 s清零输出。数据端手柄采样仍按现有3 s时效处理，短暂断流不撤销已认证控制权。本次未修改这些规则。

实验记录现在默认开启，独立于力反馈开关，详见同目录“实验记录说明.md”。主端和数据端需一起更新。

## 8. 记录与同步部署

本轮 `session.json` 的 `schema_version` 从7升为8，`force.csv` 在原16列后追加：

- `ff_582_out_f`、`ff_587_out_f`：数据端发出的轴向环境力，N。
- `ff_582_out_n`、`ff_587_out_n`：数据端发出的扭矩，N·m。
- `hold_582_active`、`hold_587_active`：对应侧保持是否有效，1/0，包含过渡期间。

记录在本拍力反馈计算后读取；旧测量列的含义和顺序保持不变。新增列不包含宿主本地阻尼与最终限幅。

首次更新应同步替换主端（包含HandleHost子目录）和数据端运行文件，本轮不涉及PLC。后续仅调宿主常量时，使用主端现有构建入口重新编译即可自动构建并复制手柄宿主。

## 9. 现场调参

1. **看阻尼力大小。** 启动主端后会弹出手柄宿主控制台。开启力反馈，以平时速度推拉，观察“速度原始值”和“阻尼力”。正常操作速度下阻尼力绝对值目标约0.2～0.4 N。若只有0.00x N，按 `DAMPING_B = 目标阻尼力绝对值 / 速度原始值绝对值` 估算新值；若频繁出现“阻尼限幅=是”，按同样公式调小。使用推拉时的非零速度原始值。
2. **确认方向。** 机器人不接触任何东西，取零后开启该侧力反馈，此时环境力约0。推拉感觉变沉说明方向正确；若手柄被带着走或越推越快，立即关闭该侧力反馈，把 `DAMPING_SIGN` 改为−1，再编译。
3. **观察振荡。** 复现此前易振荡的动作。仍振荡时，在阻尼力不超过约0.5 N的前提下增大 `DAMPING_B`。推拉换向时力翻转太突然，将 `FORCE_SLEW_N_PER_S` 降到5；力跟不上则升到12。
4. **重新编译。** 修改 `Program.cs` 顶部常量后重新编译主端。调好后，把宿主和 `HandleService.cs` 中的 `SHOW_FORCE_CONSOLE` 同时改为false，再编译并重新启动主端以隐藏控制台。
