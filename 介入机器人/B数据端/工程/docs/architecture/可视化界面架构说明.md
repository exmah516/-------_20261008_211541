# 界面架构说明

## 主端

`介入机器人/A主端/工程/master/MasterConsole` 是远程操作界面，只负责介入机器人。主端通过 `RemoteRobotLink` 与数据端通信，通过 `HandleService` 访问本机手柄。操作方向为递送/撤出；状态区显示导丝和导管各自的轴向力、扭矩。

界面保留连接终端、准备、开始控制、力反馈及既有器械和定位臂操作。主端不直接访问 ADS。

## 保留的命名管道后端

`AdsControlUI` 工程及本地启动入口已移除，B 端无键盘控制入口。`ADS.exe` 中的 `VisServer` 和 `ADS_Control_Vis` 命名管道后端暂时保留；收到的管道命令与远程命令仍进入现有控制流程，当前随包不提供本地 UI 客户端。

- 状态：C++ `vis_server.h` 的 `VisState` 按 1 字节对齐，当前固定为 871 字节；原 C# 客户端已随 UI 移除，远程网关仍使用此共享类型。
- 命令：版本化头为 24 字节，UTF-8 负载上限 1024 字节。
- 实验记录命令：25 开始、26 停止；28 为纯净力监视。
- 已停用的命令号 7、20、27、48 保留空洞，不能重新编号。

旧 `camera_*` 字段保留在 C++ 状态结构中，当前置零，用于维持既有字节偏移；没有采集、录像、预览或转发调用。本次保留管道状态布局。

运行入口见各端 `使用说明.md`。实验数据格式见 [实验记录说明](../guides/实验记录说明.md)。
