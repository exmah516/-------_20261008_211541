# 项目架构总览

## 1. 工程位置

介入机器人保留 A主端、B数据端、C从端：A 运行 `MasterConsole`；B 运行 `ADS.exe`，可另开 `AdsControlUI` 本地调试台；C 保留现场 PLC 文件。

- A：`介入机器人/A主端/工程/master/MasterConsole.sln`。
- B：`介入机器人/B数据端/工程/ADS项目/ADS.sln`。
- 启动和网络配置见软件包根目录的 `主从分机部署教程.md`，各端入口见对应 `使用说明.md`。

## 2. 模块边界

主端负责介入界面、本机手柄、远程命令和触觉输出。数据端负责 ADS 通信、运动、力采集与反馈、定位臂、远程网关和实验记录。

主端与数据端使用 TCP 32000 和 UDP 32001；数据端与本地调试台使用命名管道。网络协议、PLC 符号和控制算法不因目录清理改变。

## 4. 主循环骨架（`main.cpp` 主循环 `while(true)`）

ADS 通信线程按 100 Hz 读取快照并应用输出。主循环消费快照，处理通信恢复和手柄输入，推进准备、递送/撤出及换手流程，发布运动与力反馈输出，并将实验样本入队；磁盘写入由异步记录线程处理。定位臂由独立低频 ADS 服务管理。

跨文档定位以函数和类型为准，旧文档的步号、行号只作历史参考。
