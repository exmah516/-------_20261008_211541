# VTK 演示说明

本文件保留在介入工程中作为历史入口说明。当前演示脚本已经归档到 `造影机器人/B数据端`。

1. 在介入机器人 A主端启动 MasterConsole，并切换到模型显示区。
2. 运行 `造影机器人/B数据端/发送VTK模型测试.cmd`。
3. 脚本通过 TCP `32110` 发送 sj1～sj7、xj1～xj2 的显示测试值，完成后回到零位；不启动 ADS，不连接 PLC，也不发送真实机器人命令。

若运行独立接收窗口，先关闭 MasterConsole，避免同时监听 `32110`。真实跨机测试需确认 `192.168.50.1`、`192.168.50.2` 和防火墙。
