# 介入机器人 B数据端

这里运行介入机器人电脑侧数据端：现有 `ADS.exe`、PLC 通信、机器人运动、远程手柄、力反馈、定位臂和远程网关。本地调试 UI、键盘控制和本地手柄测试入口已移除；ZenohService 已替换旧网关与命名管道。

- 工程：`工程/ADS项目/ADS.sln`
- 日常启动：`编译并启动数据端.cmd`
- 兼容入口：`编译并启动从端.cmd`

定位臂主端顶部的“快 / 中 / 慢”统一调整五轴点动速度，默认中档：快=原速×2，中=原速，慢=原速×0.5。切档后再按住轴的 `+ / −` 点动，松手即停。需同时更新主端与数据端运行文件，PLC 工程无需修改。

海康转发已整体迁移到 `影像传输/B数据端/ScreenCut`，不再随 ADS 启动。更新时重新编译本数据端并关闭旧 ADS，避免旧程序占用摄像头端口。ADS、PLC 接口和机器人控制协议保持原有实现。
