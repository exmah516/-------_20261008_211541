# 窗口与单向换手修改验证（2026-10-13）

修改工程：`B_从端电脑/工程/ADS项目/ADS.sln`。

递送、撤出统一为 axis1 距左限位 5～30 mm、axis6 间距 g=3～33 mm，无外扩。
主动 axis6 换手目标为递送 33、撤出 3；被动目标均为 g=5。
axis1 换手时，axis6 距当前方向主动触发端小于 3 mm 才提前合并；axis6 触发不提前带动 axis1。

## 回归证据

- `before/dual_control_test.log`：原有测试通过（9,000 组、66,560 条断言）。
- `regression_before_fix/dual_control_test.log`：新用例在旧逻辑下失败，复现 axis6 单独触发带动附近静止 axis1。
- `final_offline/dual_control_test.log`：修改后 11,700 组边界组合、89,296 条断言通过，含严格 3 mm 边界、两方向目标校验、无外扩、零输入、相反输入、独立/同时触发、B6 和屈曲恢复退出。
- `final_offline/test_source_hashes.json`：实际被测源码摘要。
- `build_debug.log`、`build_release.log`：本地 ADS 与 AdsControlUI 的 VS2022 x64 解决方案构建记录。

运行离线用例：

```powershell
python -X utf8 "B_从端电脑/工程/ADS项目/tools/run_dual_control_test.py" "验证记录/窗口调整_20261013/final_offline"
```

## 轨迹结果与范围

`final_offline/trajectories.csv` 使用生产运动分支加理想 PLC 替身，共 10 条连续轨迹，每条 1,000 拍。
单独前推导管实际 99.3 mm，共 7 次换手；单独撤导管实际 94.8 mm，共 52 次换手。
撤出时被动目标 5 距触发端 3 仅 2 mm，因而需要频繁被动换手。
这组统计不包含真实夹爪等待、轴速度和 PLC 跟随误差，不能用于估算手术用时。
