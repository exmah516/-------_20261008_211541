# 三工程拆分与主端界面规划

更新时间：2026-10-18

本文只记录当前重构范围和界面要求。历史验证记录继续保留，但与本文冲突时以本文为准。

## 1. 三个工程

### 血管介入机器人

- 主端：介入机器人操作界面、手柄、递送/撤出控制、定位臂操作。
- 数据端：现有 `ADS.exe`、运动同步、力反馈、实验记录和远程网关。
- PLC：沿用现有 ADS 接口和现场 PLC 程序，本次不改 PLC。

### DSA 机器人远程控制

- 主端：VTK/URDF 模型和必要的 DSA 手柄控制。
- 数据端：接收 DSA 控制帧，做最小校验，并发送模型运动状态。
- DSA PLC：当前没有提供，先保留执行入口并支持演示数据。

### DSA 影像和海康监控

- 主端：DSA JPEG 影像、监控1、监控2。
- 数据端：独立运行海康 TCP 转发；从现有 `ADS.exe` 中移出 `HikCameraRelay`。
- DSA 电脑上的 `ScreenCut` 保持独立运行。

五轴“定位臂”属于血管介入机器人 PLC，不属于 DSA VTK 模型。

## 2. 主端 UI

### 血管介入机器人主端

只保留实际操作需要的内容：

- 连接/断开按钮；
- 当前方向：递送或撤出；
- 必要的操作参数；
- 导管、导丝、电缸、夹持、注射器、轴4和定位臂操作；
- 必要的参数输入和停止按钮。

不新增以下界面区域：

- 控制权；
- PLC 状态；
- 急停状态卡片；
- 通信或诊断；
- 报警；
- 日志。

这些内容仍由底层控制程序处理，不在主端重复展示。

窗口按右上区域的小尺寸设计，建议约 `700×500`。内容超过高度时使用纵向滚动；不做折叠面板，也不做复杂自适应布局。

当前最新版 XAML 仍有状态区、力/扭矩、角度、净距离、“开始控制”和定位臂反馈等旧控件；这里写的是拆分后的精简目标，后续 UI 重构时再删除不需要的部分。

### DSA 机器人主端

以 VTK 模型和必要的控制输入为主，不增加连接状态、使用状态、手柄状态、速度、控制发送、模拟数据或数据端状态面板。

### 影像监控主端

只显示 DSA 影像、监控1和监控2，并保留画面切换或放大操作。连接细节留在程序内部。

## 3. 当前方向显示的来源

当前主端的“方向”来自：

```text
介入机器人/A主端/工程/master/MasterConsole/ViewModels/MainViewModel.cs
MainViewModel.ModeText
```

当前实现是：

```csharp
Has(StatusFlags.GlobalReverse) ? "撤出" : "递送"
```

所以主端只显示“递送”和“撤出”两个方向。数据端内部的 `GuidewireMode::None`、`Independent`、`Cooperative` 是控制实现分支，不是主端需要展示的三种模式。

第一阶段目录迁移已完成：介入 A/B 保留原工程，造影 B 保留 VTK 演示脚本，影像 B 数据端保留 ScreenCut。DSA PLC 尚未提供，影像转发暂随介入 B 的 ADS 工程保留。

## 4. 现有代码迁移边界

### 介入主端移出

- `RobotViewport`、`UrdfStruct`、URDF 资源和 VTK 依赖；
- `DsaCanControlSender`、`LegacyControlCommand` 和 DSA 专用 CAN 依赖；
- DSA JPEG 接收和海康显示。

### 介入数据端移出

- `HikCameraRelay` 及其启动/停止代码；
- 与 DSA 手柄发送有关的 `RemoteRobotLink` 注入和循环。

DSA CAN 不能简单地从介入链路复制出来。拆出后要使用 DSA 自己的会话、使能和超时条件。

### DSA VTK 数据

现有 `32110` 和 `send_vtk_motion.ps1` 是测试链路：它用于发送有限的演示轨迹，完成后主动结束连接。保留为测试入口；正式数据端另留持续状态发送入口。

## 5. 失焦处理

不新增复杂焦点管理、鼠标离开检测或跨窗口状态机。保留现有 `Window_Deactivated` 对“按住才动”动作的停止处理即可，防止切换到其他窗口后按钮抬起事件丢失。普通鼠标移出按钮不作为停止条件。

## 6. 实施顺序

1. 冻结现有介入机器人和 PLC 接口。
2. 迁出影像主端和海康转发，验证独立启动/停止。
3. 从介入主端和 `RemoteRobotLink` 中移出 VTK、DSA CAN 发送及相关生命周期。
4. 建立 DSA 数据端最小网关和演示状态发送。
5. 将介入主端改为小窗口、纵向滚动和精简操作区。
6. 分别启动、停止三个主端和三个数据端，确认互不影响。

## 7. 验收

- 介入主端能连接、显示递送/撤出并完成原有操作。
- DSA 主端能显示 VTK 模型，演示数据能驱动模型。
- 影像主端能显示 DSA 影像和两路海康画面。
- 停止任一 DSA 或影像程序不影响介入控制。
- 窗口内容超出高度时可以滚动；不要求折叠或复杂自适应。
- 没有 DSA PLC 时，界面和文档不宣称真实 DSA 机器人已执行运动。

## 8. 不在本次范围内

- 重新设计介入控制算法；
- 修改现有 PLC 程序或 ADS 符号；
- 为主端增加控制权、PLC、急停、通信、诊断、报警、日志状态面板；
- 为 DSA 主端增加连接、使用、手柄、速度、模拟数据或数据端状态面板；
- 把内部控制枚举直接做成三种用户模式。
