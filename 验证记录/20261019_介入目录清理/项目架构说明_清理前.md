# 三端工程结构

项目按业务拆成三组，每组都使用 A主端、B数据端、C从端：

- 介入机器人：A主端负责血管介入机器人界面、手柄和远程命令；B数据端负责 ADS/PLC 和机器人控制；C从端预留 PLC 工程。
- 造影机器人：A主端负责 VTK/URDF 模型和运动数据显示；B数据端发送当前 VTK 演示运动数据；C从端预留 DSA PLC 工程。
- 影像传输：A主端负责 DSA JPEG 和两路海康监控显示；B数据端运行 ScreenCut 截屏发送；C从端预留。

主端工程：

- 介入机器人/A主端/工程/master/MasterConsole.sln
- 造影机器人/A主端/工程/DsaMaster/DsaMaster.sln
- 影像传输/A主端/工程/ImagingMaster/ImagingMaster.sln

端口约定：

- 造影模型运动：TCP 32110
- DSA JPEG：UDP 36661、36663
- DSA 截屏控制：UDP 36662、36664

本次拆分采用复制公共工程资源、按职责替换入口窗口的方式，保留原有介入控制协议、VTK 帧格式和影像接收协议。DSA PLC 程序当前缺失，造影 A主端暂时只接收并显示运动数据。
