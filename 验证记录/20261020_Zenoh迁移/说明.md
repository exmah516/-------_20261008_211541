# 介入机器人 Zenoh 迁移记录

2026-10-20：介入机器人 A 主端与 B 数据端已切换为 Zenoh + MessagePack；原主端 TCP/UDP/JSON 和本地命名管道传输已退出活动工程。PLC 程序、控制算法与原控制循环门控沿用现有实现。

## 当前实现

| 内容 | 位置与行为 |
|---|---|
| 主端网络服务 | `介入机器人/A主端/工程/master/VI.Service.Net`；net472/x64，直接调用 Zenoh-C，提供泛型发布、订阅和序列化接口 |
| 主端调用边界 | `MasterConsole/Services/RemoteRobotLink.cs`；保留 `IRobotLink`，不管理路由器 |
| 数据端网络服务 | `介入机器人/B数据端/工程/ADS项目/zenoh_service.h/.cpp`；回调接收与原控制循环分开 |
| 协议镜像 | C# `MasterConsole.Protocol/ZenohFrames.cs`、C++ `ADS项目/protocol/cpp/zenoh_protocol.h` |
| 字段说明 | `介入机器人/A主端/协议/PROTOCOL.md`；按当前实际载荷定义，各端副本同步更新 |
| 固定黄金样本 | `protocol/fixtures/zenoh-v1`；两端读取同一组预制 Hex，包含错误类型和长度样本 |
| 锁定依赖 | `zenoh/sdk`：Zenoh-C/C++ 1.10.1、msgpack-cxx 9.0.0；C# MessagePack 3.1.12 |

四个 Topic 为 `vi/ads/handle/v1`、`command/v1`、`state/v1`、`force/v1`。手柄顶层数组为 24 项，含协议头、两只手柄各 8 项、三个方向值和认证数据；不嵌套手柄数组。命令、状态、力反馈分别为 15、49、13 项。普通命令结果并入状态帧，准备位置与开始控制各有任务状态和关联命令 ID。

命令在 ADS 本地入队，FIFO 上限 256，满时丢弃最旧项并记日志；消费前检查本地排队时间，超过 2 秒拒绝。会话、序号、认证和原控制门控继续检查。点动与保活不占 32 项结果队列。主端不缓存或重发命令。

两机不比较绝对时间或单调时钟起点。ADS Echo 主端单调毫秒，主端计算 RTT。连接要求 Session 可用且 500 ms 内收到有效状态。未增加软件急停，定位臂停止与现有 PLC 急停路径保持各自语义。

## 启动与部署

1. 数据端使用 `介入机器人/B数据端/编译并启动数据端.cmd`；默认监听 `tcp/192.168.60.1:7447`。ADS 启动或复用路由器，只关闭自己启动的路由器。
2. 主端使用 `介入机器人/A主端/编译并启动主端.cmd`，再操作“连接终端”。默认连接数据端 `192.168.60.1:7447`。
3. 两端 `工程/config/remote.token` 必须相同。复制整个软件包可保留当前路径；若只部署输出目录，须携带输出内全部依赖，并将同一份 `remote.token` 放 EXE 旁。数据端另须携带 `zenohd.exe`。

数据端监听地址在 `ADS项目/zenoh_service.h` 的 `ZenohServiceConfig.endpoint`；主端默认地址在 `RemoteLinkSettings.Host` 和 A 端 `工程/build-and-run.ps1`，也支持 `--host`。网络需允许数据端 TCP 7447，原 32000/32001 不再用于介入主数据端通信。

普通短命令“成功”表示通过服务门控并由原控制循环消费，不代表实体机构已经到位。准备位置、开始控制及需要观察状态的操作通过对应状态确认。

## 可重复验证

在本目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\验证.ps1
```

该脚本只构建 A/B 两端的 Release、Debug，并运行协议和模拟通信测试，不启动真实 `ADS.exe`。C++ 模拟端仅使用内存快照，不链接 ADS/PLC 库。完整输出写入本目录 `验证_日期_时间.log`。

最后一次完整验证日志：[验证_20261020_150711.log](验证_20261020_150711.log)，2026-10-20 15:08 全部通过。

已通过的检查：

- A/B 两端 Release、Debug 构建与运行依赖检查；主端 0 警告、0 错误。
- C++ 协议 54 项、C# 协议与跨语言通信 79 项，均无失败。
- C++ 服务边界：FIFO 顺序、溢出、2 秒时效、手柄独立接收、会话与序号、32 项结果排除点动/保活、长任务关联及资源切换。
