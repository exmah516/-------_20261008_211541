# 截图与监控使用说明

新版可分别部署到不同电脑。完整步骤见 [有线分机部署与画质设置](有线分机部署与画质设置.md)，包括三台电脑的 IP、主端两个连接地址、端口、画质档位和海康码流设置。

- 截图电脑复制整个“截图端”，启动 ScreenCut.exe。下排选 1080p 或手动填写分辨率、帧率、码率，点“开始传图 / 应用画质”。
- 监控电脑复制整个“监控端”，启动 CameraMonitor.exe。海康画质在设备端配置，监控端 INI 的 stream=0/1 分别选主/子码流。
- 各发送电脑的 streaming.config 填自己的 IP 和主端 IP；主端实际运行目录的两个 INI 分别填截图电脑和监控电脑的地址。
- 主端更新完整运行包后自动启动本地中继和录像，状态区显示会话目录；最小化或隐藏不影响录像，正常退出会等待写完文件。
- 首次生成会迁移旧包的相机和截图区域设置；已有新包配置保留。不要用旧 EXE.config 整份覆盖新文件。
- 切换前关闭旧版软件，部署时复制完整文件夹。两发送端日志在程序目录，主端日志随录像会话保存。
