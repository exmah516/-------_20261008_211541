# 影像数据端截图发送工具 ScreenCut

`ScreenCut.exe` 在 DSA 电脑上运行，负责截取 DSA 窗口、压缩为 JPEG，并通过 UDP 发送给主端。它是独立程序，不依赖 ADS、PLC、VTK 或 CAN。

## 当前文件

- `ScreenCut/ScreenCut.exe`：现成运行程序
- `ScreenCut源码/ScreenCut.sln`：独立源码工程
- `文件校验_SHA256.txt`：历史校验记录

## 当前主端接收位置

```text
介入机器人/A主端/工程/master/MasterConsole/Services/DsaJpegReceiver.cs
介入机器人/A主端/工程/master/MasterConsole/Controls/DsaImageView.xaml.cs
介入机器人/A主端/工程/master/MasterConsole/Views/MainWindow.xaml.cs
```

启动介入 A 主端后，再启动 ScreenCut；不需要启动介入 B 的 ADS。主端读取 DSA 配置模板：

```text
介入机器人/A主端/工程/config/dsa_screencut.ini.example
```

默认影像端口仍为 UDP `36661`，第二路为 `36663`。本阶段不修改 ScreenCut 的截图、JPEG 或 UDP 协议。

## 运行方式

1. 在 DSA 电脑打开 `ScreenCut/ScreenCut.exe`。
2. 让 DSA 影像窗口显示在指定区域，填写截图矩形和主端 IP。
3. 在主端启动 `介入机器人/A主端/编译并启动主端.cmd`。
4. 在 ScreenCut 中启动对应的持续传图按钮。

本目录只归档 ScreenCut。影像显示主端和海康监控仍在介入 A；海康转发暂随介入 B 的 ADS 工程保留，后续再整体迁出。
