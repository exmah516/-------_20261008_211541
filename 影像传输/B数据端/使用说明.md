# 数据端使用

1. 将整个 `ScreenCut` 文件夹复制到数据端，不要只复制 EXE。
2. EXE.config 设置主端 `192.168.50.1`、本机 `192.168.60.1` 和两路相机 IP/网口；`config/hik_cameras.ini` 填相机凭据。
3. 数据端放行 TCP 8889、UDP 8189 和 TCP 8189；UDP 是低延迟首选，TCP 8189 仅作为建连时 UDP ICE 不可用的备用候选。启动 ScreenCut，预览桌面裁剪区域，点“开始传图”。
4. 主端启动 ImagingMaster；三路视频自动连接。没有接入的摄像头会单独显示无画面，不应影响 DSA 或另一路摄像头。主端 3 秒无解码帧时遮住旧画面，8 秒无解码帧才重建会话。停止传图仅停 DSA，关闭 ScreenCut 才关闭媒体服务。

摄像头必须输出普通 H.264，不用海康 SDK。完整配置表、回环测试和故障定位见上级 `README.md`。
