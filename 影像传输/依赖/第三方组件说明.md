# 固定的媒体依赖

| 组件 | 版本 | 来源/用途 |
| --- | --- | --- |
| MediaMTX Windows amd64 | 1.21.2 | bluenviron/mediamtx 官方 GitHub Release；RTSP → WebRTC，MIT |
| FFmpeg Gyan essentials | 9.0.2 | gyan.dev/ffmpeg 官方列出的 Windows 构建提供方；GDI 采集与 libx264，GPL v3 构建 |
| Microsoft.Web.WebView2 SDK | 1.0.4258.31 | Microsoft 官方 NuGet；兼容 net472，随包有 x64 Loader，不包含 Evergreen Runtime |

运行库位于 `runtime`，WebView2 本地包在 `nuget`。`准备依赖.ps1` 固定下载地址和 SHA256，支持已有依赖的离线校验。MediaMTX 的 WHEP reader.js 随主端 Player 本地部署，保留 MIT 许可证；不使用 CDN。

MediaMTX：<https://github.com/bluenviron/mediamtx/tree/v1.21.2>。
FFmpeg 源码：<https://github.com/FFmpeg/FFmpeg/tree/n9.0.2>；构建说明和对应源码获取方式：<https://www.gyan.dev/ffmpeg/builds/>。
WebView2 SDK：<https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4258.31>；运行时：<https://developer.microsoft.com/microsoft-edge/webview2/>。

重新分发媒体二进制时请同时保留 runtime 中许可证及对应项目的授权/源码提供要求。WebView2 SDK 包内的 LICENSE.txt 保留在本地 NuGet 包中。
