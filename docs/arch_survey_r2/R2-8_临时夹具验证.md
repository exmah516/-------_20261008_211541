## 8.3 推断二：Active的等量、限速、余量和退出

**已确认**：Active使用的是`axis1_linear_increment_mm`的正量，不是`axis6_linear_increment_mm`。双柄拓扑下它来自587，虽然Active日志注释写“582 手柄”。按源码应以587轴1输入为准。出处：`D/main.cpp:130-148,3340-3356`。夹具直接注入已滤波、缩放、死区后的轴1增量，不验证物理柄的单位换算。

动作公式（**已确认**；`D/main.cpp:3215-3226,3343-3388`）：

```text
dt_ms=min(now-last_motion_tick,50); last_motion_tick=now
pending = input_axis1>0 ? pending+input_axis1 : 0
remaining=max(0,min(650-x3_cmd,665-x5_cmd,min(665,660)-x6_cmd))
step=min(pending,40*dt_ms/1000,remaining)
cmd3+=step; cmd5+=step; cmd6+=step
pending-=step; moved+=step
if remaining_after<=0.2: pending=0
```
