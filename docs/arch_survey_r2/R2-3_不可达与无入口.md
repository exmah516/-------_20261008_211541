## 对“删除会波及哪些测试”的边界

上述删除分析的粒度为“删表中分支/命令处理代码”，不是删除其整个共享模块。当前 runner 的抽取片段明确包含 `mapping_helpers`、`mapping_begin`、`single_mapping`、`mapping_guard`、`mapping_complete`，因此删除映射实现会影响 `dual_control_test`（**已确认**，`tools/run_offline_tests.cjs:34-66`）。删除 `ModeSelection/apply_mode_selection` 实现会影响同测试的 `mode.inc`，不能因其公共入口缺失就连同 helper 一并认定为无测试依赖（**已确认**，`tools/run_offline_tests.cjs:50-53`、`tools/dual_control_test.cpp:328-351`）。

**已确认**：`SetGravityCompensation` 虽未映射公共命令，其 case 标签是另外三个 runner 抽取 `SelectDirectControl` 的结束标记；若直接删除标签，这些 runner 会先因标记丢失而失败：`tools/run_offline_tests.cjs:97`、`tools/run_ads_diagnostics_test.py:52`、`介入机器人/tools/revision_uhn/run_network.py:37`。这是文本抽取耦合，不是重力补偿行为覆盖。
