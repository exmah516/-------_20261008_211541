# 第1节：PLC换手事务执行器

当前接口版本为1。命令和状态结构采用pack_mode=1；命令117字节，状态61字节。完整定义见ST_HandoffCmd、ST_HandoffStatus。

- 阶段：0空闲、10持有者夹紧、20移动者松开、30内部回退、40移动者夹紧、50持有者松开、60等待接管。
- phase_ms：下标1至5依次对应10/20/30/40/50；6、7分别为轴1、轴6运动耗时；8保留。
- error_code：1拒绝（reject_reason：1忙、2状态、3参数），2停用失败，3运动错误/中止，4子流程超时，5被打断。nc_error_code提供NC原始错误码。
- status额外回显leg_mask，供数据端进程重启后接管已有事务。
- 参与轴在30至接管期间冻结参考并旁路原平滑链；停稳后对齐全部轨迹历史，清零速度/加速度。
- 原上位机return_cmd、fast和startup_smoothing_bypass接口已删除；轴3/5不再参与内部回退。
